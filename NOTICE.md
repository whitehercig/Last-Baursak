# Source provenance

The host scaffold (`src/base/`, host configuration and platform bootstrap) was obtained from the official @idosgames/mcp package, version 0.1.27, from its bundled registry/host.json on 2026-10-05. Runtime versions were obtained from that registry's index.json.

The original iDos Games runtime packages are MIT-licensed. Their package licenses and notices remain in their npm distributions. The Last Baursak gameplay, renderer, illustrations, relay API and project documents were authored for this project.

Official project: https://github.com/iDos-Games/iDosGamesSDK_TS
Official tools: https://idosgames.com/mcp/

Using the scaffold does not establish that this source has been generated in an actual publisher's AI Coder project. That platform step is still pending and is tracked in docs/VALIDATION.md.
