# Last Baursak — что уже можно сделать

Открой http://127.0.0.1:5187/ в браузере на этом компьютере. Игра работает, пока в этом чате запущен локальный сервер.

**Управление:** WASD или стрелки — движение, пробел — придержать поднос. Доберись до комнаты 201 наверху. Кнопка паузы находится в правом верхнем углу игры. На телефоне есть джойстик и кнопка удержания.

Если сервер остановился, открой терминал в этой папке и выполни:

```sh
npm ci
npm start
```

## Уже сделано

Игровой забег с физикой подноса, препятствиями, котами, таймером и перезапуском. Мобильное управление. Экран эстафеты. Подписанный вход через кошелёк. Серверная проверка записанных движений. Подготовка настоящих Solana Devnet транзакций выдачи и передачи уникального предмета. Документация для GitHub и черновик описания для заявки.

## Следующий шаг, который требует тебя

Зарегистрируйся на https://platform.idosgames.com/, создай проект Last Baursak через AI Coder и пришли ссылку в этот чат. Инструкции: `docs/IDOS_SETUP.md`. Локальные исходники подготовлены для переноса, но аккаунт и настоящий проект ещё не созданы.

Для проверки эстафеты понадобится кошелёк Phantom / Solflare с тестовыми SOL в Solana Devnet. Публичный кран во время нашей проверки отказал в выдаче; https://faucet.solana.com/ предлагает другие способы получения тестовых SOL.

Игра ещё не опубликована и не подана на хакатон. Настоящее выполнение mint/transfer в блокчейне, перенос в iDos Games AI Coder и финальное видео остаются обязательными шагами.
