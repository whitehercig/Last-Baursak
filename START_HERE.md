# Last Baursak — с чего начать

- **Опубликованная игра iDos Games:** https://4nkmxdoj.idos.games/
- **Страница игры:** https://idosgames.com/app/4NKMXDOJ/
- **Исходники:** https://github.com/whitehercig/Last-Baursak

Нажми «Начать забег». За 45 секунд доберись до комнаты 201: двигайся WASD или стрелками, обойди кота и придерживай поднос пробелом. На телефоне есть экранные стрелки и кнопка «Придержать». Играть можно без кошелька.

В разделе «Эстафета» можно подключить Solana-кошелёк и подписать уникальное сообщение для подтверждения игрового адреса. Для этого не нужны SOL и транзакция. В опубликованной игре пока нет токена или передачи предмета в блокчейне.

Репозиторий также содержит более сложный локальный прототип с физикой подноса и API для Solana Devnet. Чтобы запустить его на этом компьютере:

```sh
npm ci
npm start
```

Открой http://127.0.0.1:5187/. Локальный прототип и его видео отличаются от опубликованной версии iDos Games. Статус каждого компонента указан в [README.md](README.md) и [docs/VALIDATION.md](docs/VALIDATION.md).

До заявки на Colosseum остаются два отдельных шага: снять видео именно опубликованной игры и привязать игру к подходящему проекту на площадке.
