# Demo video — published iDos Games build

[Watch the English v7 walkthrough](../demo/live-idos-v7.mp4). It uses still frames captured in sequence from the public game at https://4nkmxdoj.idos.games/ after the v7 release. The explanatory panel and frame durations were added in editing. It is a walkthrough of real public-game states, not a continuous screen recording.

The captured sequence shows a failed attempt, retry, use of the steady control, reaching room 201, and the relay page. No wallet was installed in the capture browser. The video therefore does **not** demonstrate a completed wallet signature or an on-chain handoff. The live game requests no transaction and can be played without SOL.

An older [continuous v6 browser capture](../demo/live-gameplay-raw.webm) and [edited v6 video](../demo/live-idos-v6.mp4) are retained for comparison. They show the former Russian interface and should not be used as the current submission demo.
